# 第三阶段验收报告

> 本文保留第三阶段的验收快照。当前交易流程与最新测试结果见[第四阶段验收报告](stage-4-verification.md)。`target/` 下的生成报告随构建更新。

验收日期：2026-10-21。版本：`1.0.0-SNAPSHOT`。

## 1. 完成内容

- 接入 MyBatis 3.0.5 Starter、MySQL 驱动、Flyway；提供 MySQL 和 H2 文件数据库配置。
- 增加商品、优惠券、订单、订单明细、订单优惠快照五张表，以及版本化迁移和初始数据。
- 原有商品查询、优惠券查询和结算预览改为读取数据库，保留原有 HTTP 契约。
- 新增订单创建、查询与状态更新接口，订单金额、商品、地址和优惠规则使用历史快照。
- 主表、明细与优惠快照在同一事务中保存；状态更新使用状态机和带旧状态条件的 SQL。
- 补充 [MySQL 配置、架构与订单接口文档](database.md)及 [Compose 配置](../compose.yaml)。

本阶段不扣减/预占库存、不核销用户优惠券，也不处理创建请求幂等、用户鉴权或真实支付。上述能力属于后续交易流程开发。

## 2. 验收环境与命令

使用 Java 17、Spring Boot 3.5.16、MyBatis Starter 3.0.5、Flyway 11.7.2、H2 2.3.232 和原生 MySQL Community Server 8.4.13。

本次 MySQL 验收使用官方 ZIP 便携版，运行在回环地址的随机端口和独立临时数据目录中，未安装 Windows 系统服务。测试账号只拥有专用 `order_settlement_test` 库的权限。

设置专用测试连接环境变量后执行：

```powershell
mvn -B -ntp -Pmysql-it clean verify checkstyle:check spotbugs:check
```

| 检查 | 结果 |
|------|------|
| 干净构建及可执行 JAR 打包 | BUILD SUCCESS |
| Surefire 常规测试 | 182 次通过，失败/错误/跳过均为 0 |
| Failsafe 原生 MySQL 测试 | 16 次通过，失败/错误/跳过均为 0 |
| Checkstyle | 0 项违规 |
| SpotBugs | 0 项缺陷、0 项分析错误 |

沿用现有静态规则与排除配置，未新增 SpotBugs 排除项。数据库迁移已在两个数据库引擎上实际执行；原生测试发现的跨字段 CHECK 约束差异已修正为表级约束。

## 3. 测试组成与证据

| 范围 | 执行数 |
|------|------:|
| 第一、二阶段回归测试 | 164 |
| OrderPersistenceTest | 14 |
| OrderAtomicityTest | 2 |
| PersistenceRestartTest | 1 |
| OrderConflictTest | 1 |
| 常规测试合计 | 182 |
| MySqlPersistenceIT（复用持久化场景） | 14 |
| MySqlAtomicityIT（复用回滚场景） | 2 |
| 两套环境执行总数 | 198 |

计数依据 Surefire / Failsafe 总计与 XML 的实际 `<testcase>` 节点，参数化输入按执行次数统计。MySQL 的 16 次执行复用同一行为契约，不代表新增 16 个不同业务场景。

关键验证：

- 修改数据库价格、库存和优惠规则，HTTP 请求读取到新值。
- 订单创建与查询、重复商品合并、多商品顺序、三类优惠快照顺序、空券列表和小额金额精度正确。
- 修改或删除商品与优惠配置后，历史订单名称、单价、优惠与最终金额保持原值。
- 预览不写入订单；参数校验失败不产生订单。
- 商品明细写入失败回滚主表；优惠快照写入失败回滚主表和明细。这些测试没有外层测试事务，验证实际仓储事务回滚。
- 合法状态更新可查询，终态修改返回 409；陈旧状态条件无法覆盖先成功的更新。
- 编号大小写和尾部空格严格匹配；带 SQL 片段的输入被当作普通参数。
- 关闭整个 Spring 上下文和文件数据库后重新打开，订单、状态与修改后的商品价格仍然存在，种子数据不会覆盖变更。

## 5. 打包后真实 HTTP 验收

以 `java -jar` 和 `mysql` profile 启动最终构建产物，在本机随机端口调用接口：

- 商品查询返回 3 件商品，结算预览应付 62.00 元。
- 创建订单返回 201，Location 指向新订单；状态更新返回 PAID。
- 关闭应用进程后重新启动，按原订单号查询，金额仍为 62.00、状态仍为 PAID，三张优惠券快照完整保留。

结果记录在 [JAR 重启验收结果](../target/stage3-jar-smoke.json)。验收后已关闭应用进程和临时 MySQL 服务。Compose 文件未在 Docker 环境执行；原生 MySQL 连接、迁移及业务流程已完成验证。
